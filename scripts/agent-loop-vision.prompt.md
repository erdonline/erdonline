# Vision 自我迭代（每 tick 现场选题，禁止写死主线）

## 北极星（不变）

服务 `docs/vision.md`：数据库设计的 Git + Figma；指标=每周有版本保存的活跃建模项目。

## 每轮必须做（顺序）

1. **读现状，不读记忆**  
   - `docs/roadmap.md`：找出仍为 🚧 / 📋 的项及括号内「待续」子项  
   - `CHANGELOG.md` Unreleased 最近几条 + `git log -5 --oneline` + `git status -sb`  
   - 勿沿用对话或旧 prompt 里的「当前主线优先级」清单（Dialect / 只读分享等），**除非** roadmap 仍明确标 🚧

2. **选题（唯一目标）**  
   - **控件矩阵 🚧 优先**：若 `docs/control-matrix.md` 仍有 🚧（或误标未删的死入口）→ **优先啃下一行可验证切片**（修闭环 / 补 E2E / 删死代码）  
   - **矩阵 📋 仅当可行动**：在 📋 中选对北极星杠杆最高、**本 tick 可验证**的一行（非 AI / i18n；非「实验不扩」/「外链不测」类纯延期）→ 闭环或明确维持 📋 并写原因  
   - **矩阵 🚧=0 时优先「下一季三件事」**：按 `docs/roadmap.md`「下一季只做三件事」顺序取第一件未闭环且本 tick 可验证的切片（① 首屏叙事+示例项目→30s 进版本保存；② 导出/版本信任链；③ 协作→版本自然发生）  
   - **否则 roadmap 📋 / 🚧**：优先已 🚧 未收口；再否则按杠杆选下一 roadmap 📋  
   - 一次只做一件事；切片须本 tick 内可验证；禁止写死功能清单，以矩阵/roadmap 状态为准  
   - **Idle（禁止假切片）**：仅当矩阵 **🚧=0** 且「下一季三件事」**三件全被外部依赖阻断**（如 MinIO/Word 基建、正式仓未就绪）时才可 idle：一行说明阻断原因即可，**勿编造**无北极星杠杆的微改；AI / i18n / 正式仓 Issue 投放为依赖外部或后置，不作为 idle 替代选题

3. **执行**  
   - 若 idle（上条）：跳过实现与伪造验证，仅在改了本 prompt 时提交该改动  
   - 若该目标已在推进：继续做到可验证收口  
   - 若停滞 / 无 WIP：立刻开做，不要只汇报计划

4. **收口**  
   验证（curl/单测/相关 E2E）+ CHANGELOG 验证点 + 文档同轮 + roadmap 状态推进 + `git commit`（遵守仓库 commit/入口规则）；idle 且无代码改动则不强制 CHANGELOG

5. **简报（短）**  
   本轮目标对应 roadmap 哪一行 → 做了什么（或 idle + 原因）→ 证据（命令/提交）→ 下一刀候选（仍从 roadmap 推导，不写死）

## 停止条件

连续两轮指标/体验变差、与用户方向冲突、或用户叫停 → 停下并说明。

# ADR-0004: Keep MIT license

- Status: Accepted (2026-08-01)
- Decision makers: Project maintainers

## Context

Project is currently MIT. Common concern for open infrastructure: cloud vendors hosting forks ("free riding"). Counter-weapons: AGPL/BUSL/SSPL copyleft or source-available licenses.

## Decision

**Keep MIT**. Current core tension is **adoption rate**, not being free-ridden — project has not built reputation yet; maximize adoption and contribution barrier reduction first. MIT is the license enterprise users trust most.

## Consequences

- Positive: lowest adoption barrier, helps become de facto standard
- Risks & mitigations: if influential hosted fork appears later, re-evaluate BUSL/AGPL (new ADR records overturn rationale)
- Supporting: add Backers/Sponsors page for sustainability (not commercialization — survival)

# 如何导入 DBML

手里有一份从 dbdiagram（或其它工具）导出的 `.dbml`？这篇把它迁进 ERD Online，让表和关系落在画布上，并建议立刻存一版当基线。

> **目标**：导入合法 DBML，表与关系出现在设计器。  
> **前置**：DBML 文本或文件；已打开**可编辑**项目（[Demo](https://www.erdonline.com/demo) 只读分享需先 **复制到我的项目**）。

## 步骤

1. 在源工具中**导出 DBML**（复制文本或下载 `.dbml`）。  
2. 打开 ERD Online **可编辑**设计器。  
3. 在空态 CTA 或项目菜单中选择 **导入 DBML**。  
4. 粘贴文本或选择文件，点击解析 / 导入。  
5. 查看画布：表节点应落在可视区；有 `Ref` 时应出现关系线。  
6. （强烈推荐）立刻 [保存版本](./save-version-and-diff.md) 作为迁入基线。

## 成功时你会看到什么

- 画布出现导入的表；能缩放、拖动、选中表与字段。  
- 若有跳过项，界面会**明确提示**（而不是静默丢弃却声称全部成功）。  
- 前缀相近的表可能出现分组 Frame 建议，可接受或忽略。

## 常见问题 / 排障

| 现象 | 可尝试 |
|---|---|
| 解析失败 / 语法错 | 用源工具重新导出；检查是否截断、是否混入非 DBML 文本 |
| 部分表或关系缺失 | 查看跳过提示；Trigger 等个别构造可能无法映射，属预期 |
| 导入后画布空白或表在视野外 | 使用适应视图 / 缩放；确认解析结果里表数量 > 0 |
| 想覆盖已有模型 | 先 [存一版](./save-version-and-diff.md) 再导入，便于回滚 |
| 只在 Demo 只读页找不到导入 | 先 **复制到我的项目**；或 [自托管](./quick-self-host.md) |

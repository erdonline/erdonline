# 如何从存量库逆向成关系图

库已经在跑、却没有最新 ER 图？用只读账号连库，把选中的表拉进画布，再存一版当「线上真相」基线。

> **目标**：连接 MySQL / PostgreSQL / Oracle / SQL Server，导入选中表。  
> **前置**：已登录且可配置数据源的项目；库账号建议**只读**。  
> **注意**：免注册 Demo / 公开分享**不能**连你的私有库 —— 请 [自托管](./quick-self-host.md) 或使用已登录实例。

## 步骤

1. 打开项目 → 项目菜单 → **数据源逆向解析**（空态也可能有 **从数据源逆向**）。  
2. **选择或新建数据源**，填写连接信息并测试连通。  
3. 选择要导入的 schema / 表（大库请先按前缀或名单筛选）。  
4. 执行解析；等待完成提示。  
5. （强烈推荐）[保存版本](./save-version-and-diff.md) 作为逆向基线。

## 成功时你会看到什么

- 画布出现选中的表；外键在支持范围内显示为关系。  
- 表/列注释、索引等按方言能力尽量带上。  
- 连接密码**不会**出现在导出的模型 JSON 里。

## 常见问题 / 排障

| 现象 | 可尝试 |
|---|---|
| 连通失败 | 检查主机/端口/防火墙；容器网络下用服务名，勿用 `localhost` 指宿主机 |
| 权限错误 | 换只读账号并授予读字典权限 |
| 表太多 / 超时 | 缩小选择范围；按 schema 或前缀分批逆向 |
| 缺索引或外键 | 看解析提示；个别方言特性可能跳过而非伪造 |
| Demo 里找不到逆向 | 正常：请 [自托管](./quick-self-host.md) 或已登录实例 |

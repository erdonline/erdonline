# 如何保存版本并查看 diff

想象你刚给用户表加了一个字段：同事明天会问「上周结构长什么样？」——这篇带你把「改动 → 存版 → 看 diff」走通一遍。

> **目标**：改一张表 → **保存版本** → 对比两版差异。  
> **前置**：能打开浏览器；有自己的可写项目（见下方 Demo 说明）。

## Demo 用户请先做这一步

公开 [Demo](https://www.erdonline.com/demo) 默认是**只读分享**，用来看图，不能直接存版。

1. 打开 [Demo](https://www.erdonline.com/demo)，确认能看到示例关系图。  
2. 点击 **复制到我的项目**（未登录会引导 **登录 / 注册**）。  
3. 进入**可编辑**设计器后，再继续下面步骤。

已有自托管或正式账号的项目：直接打开该项目即可，跳过本段。

## 步骤

1. 进入项目设计器，打开 **关系图** 画布。  
2. 单击选中一张表；在字段面板**新增或修改**一个字段（例如增加 `nickname`，类型 `VARCHAR`）。  
3. 点击顶栏 **保存版本**（或带「保存版本」语义的入口），填写版本号（如 `1.0.1`）与说明，确认。  
4. 打开 **版本管理**（版本列表 / 版本面板）。  
5. 选择两个版本做**比对**，打开 diff 视图。

## 成功时你会看到什么

- 版本列表多出一条刚保存的记录（含版本号与时间）。  
- Diff 里能区分：表的增减、字段增删改、关系变动。  
- 画布上刚改的字段还在；顶栏「相对最新版本」的状态与预期一致。

## 常见问题 / 排障

| 现象 | 可尝试 |
|---|---|
| Demo 里找不到「保存版本」 | 仍在只读分享页 → 先 **复制到我的项目** |
| 找不到「保存版本」 | 确认已在项目设计器内；看顶栏 / 版本相关入口 |
| 保存后列表没有新版本 | 刷新版本列表；检查网络是否失败后重试 |
| Diff 显示「无变更」 | 两次选到同一版，或两版之间确实没结构差 |
| 想当书签存一版但没改结构 | 可以存，但空 diff 对追溯帮助有限；有改动再存更有意义 |
| 误操作想恢复 | 回滚 / 同步到历史版本前会有确认，读清再点 |
| Agent 刚 `create_version` | 同一套版本列表打开 **diff**，通过或回滚。选 prompt `suggest-erd-version`。API 200 **不是**人批准。官方 Demo **不能**当 PAT |

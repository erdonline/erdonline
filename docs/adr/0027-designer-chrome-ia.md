# ADR-0027：产品 Chrome 信息架构（仪器盘 + 全站主题 + 单一浏览面）

- 状态：**已接受**（2026-08-09；同日修订：去顶栏存版主钮 + 进页自动探库水合）
- 决策者：项目维护者

## 背景

精密工具站（ADR-0026）落地后，设计器顶栏仍是「已落盘 / 未存版本 / 实库未知 / 保存版本 / 工单…」文案墙；登录等 `layout:false` 页未吃 `erdTheme`（antd 蓝主钮）；`/dataModels` 与 `/project/*` 两套列表密度分叉。继续在 24px 密度上抠像素 ROI 归零，需要**信息架构**决策。

## 决策

1. **全站 Theme**：`app.tsx` `rootContainer` 注入 `erdTheme`；营销壳与工作台同一 `colorPrimary`（品牌红）。
2. **状态仪器盘**：Autosave / Version / Live-DB 三语义（ADR-0022）**不合并 store**，呈现压缩为落盘 / `vX` / `DB ·` 胶囊；长说明进 tooltip/Popover/`aria`。
3. **动作分级**：顶栏常显仪器盘 + 图标动作；**不再常显「保存版本」主钮**（存版经版本胶囊 / 版本页 / 示例 CTA）。
4. **进页感应**：A 层拉最新版本基线；B 层在有 JDBC 时**自动探一次**水合 DB 胶囊（修订 ADR-0022 触发条款；仍禁止定时双向同步）。
5. **项目浏览单一视觉**：`/dataModels` 与 `/project/*` 共用 `project-list` 密度与 `ProjectTypeBadge`。
6. **表设计层级**：表名条与内签合并为一条 chrome。
7. **左树新建**：去掉与文件夹 inline `+` 重复的全局下拉；右键菜单分段。
8. **本 ADR 不做**：设计器默认暗色、ReactFlow 玻璃节点（仍遵 ADR-0010 / 0026 后置）。

## 后果

- 正面：进页即见真实状态；顶栏更干净；门面与列表同脸。
- 负面：有 JDBC 时多一次探库 RTT；无版本项目仍显示 `v—`（诚实，非故障）；存版入口改为胶囊/版本页。

# ADR-0004：维持 MIT 许可证

- 状态：已接受（2026-08-01）
- 决策者：项目维护者

## 背景

项目当前为 MIT。开源基础设施类项目常见的顾虑是云厂商托管分叉（白嫖），对应武器是 AGPL/BUSL/SSPL 等 copyleft 或源码可用许可。

## 决策

**维持 MIT**。当前阶段的核心矛盾是**采用率**而非被白嫖——项目尚未建立口碑，最大化降低采用与贡献门槛优先。MIT 是企业用户最放心的许可证。

## 后果

- 正面：采用门槛最低，利于成为事实标准
- 风险与对策：若未来出现有影响力的托管分叉，重新评估 BUSL/AGPL（新增一篇 ADR 记录推翻理由）
- 配套：补充 Backers/Sponsors 页保障可持续性（非商业化，是生存保障）

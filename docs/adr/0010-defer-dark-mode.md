# ADR-0010：暗色模式延期

- 状态：已接受（2026-08-02）
- 决策者：项目维护者

## 背景

P2「加载骨架」交付时留下「暗色 ADR 另议」。北极星是每周有版本保存的活跃建模项目；暗色不抬升该指标，且 ADR-0005 已约定 CRUD 区以 antd 默认主题为主、设计器域自研。

## 决策

1. **本阶段不做**全局暗色 toggle / 设计器暗色主题
2. 需要时另开里程碑：先出对比稿与可访问性对照，再动 token；禁止半套 `prefers-color-scheme` 散落
3. P2 体验深水区其余项已收口；暗色不阻塞 P2 关闭

## 后果

- 正面：避免与协作 / 获客抢带宽
- 负面：夜间党短期无官方暗色；可用系统浏览器强制暗色作权宜

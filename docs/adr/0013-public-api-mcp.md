# ADR-0013：公开 API / MCP（规划中）

- 状态：**📋 已规划（draft）**（2026-08-02）
- 决策者：待定
- 前置：[ADR-0012](./0012-ai-era-data-structure-platform.md) 选项 B 已接受

## 背景

ADR-0012 将「API/MCP 开放」列为平台级能力：agent 可读 schema、可提交新版本。公开 API 与 MCP server 引入新的鉴权面、速率限制与 scope 模型，不宜与落地页叙事同轮拍板实现。

## 范围（待填）

本 ADR 批准前**不实现**产品代码。待落地页上线且外部/内部对 API 需求明确后触发决策，至少覆盖：

| 议题 | 状态 |

| 鉴权模型（token / OAuth / PAT） | TBD |
| 速率限制与配额 | TBD |
| Scope（读项目 / 读版本 / 写版本 / 只读分享） | TBD |
| MCP tool 清单（先读后写，分里程碑） | TBD |
| 与现有只读分享（ADR-0007）、SQL 信任链的边界 | TBD |

## 触发条件

同时满足再开设计与实现：

1. 公开落地页已上线，叙事与「开放」卖点对齐
2. 有可验证的 API/MCP 需求（外部贡献者或内部 dogfood）
3. schema-as-code 文档（`data-format.md` 对外规范）至少可引用草稿

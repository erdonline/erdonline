# ADR-0016：体验优先 —「敢分享的美图」为主线（ICP 混合）

- 状态：已接受（2026-08-02）
- 决策者：项目维护者（用户否决「再问方向」；本 ADR 固化）

## 背景

愿景仍是「数据库设计的 Git + Figma」，北极星仍是「每周有版本保存的活跃建模项目」。  
版本保存 / 分享 / presence 已具备可用能力，但循环选题在「企业审批」「chrome 碎活」「双向实时同步 / MCP 大坑」与「UI 是否算 P2」之间反复抖动。

已证伪或否决：

- **同步即主注** — 双向 live sync / 版本分支本季投入过大、ROI 不清；falsify。
- **UI 是 P2** — 用户明确拒绝；图本身颜值与三壳同语言是激活与传播杠杆，一等公民。

## 决策（ICP 混合，非纯 A/B）

**主体验注（约 90 天）：「敢分享的美图」**

1. 逆向 / 导入 / DDL → **自动布局质量** + ReactFlow **图本身美学**（节点、边、背景、密度、字体），目标是用户愿意截图与分享。
2. 设计器 + Home + 落地页 **同一视觉语言**（`erd-*` tokens）；禁止再散落 `#4096ff` 等默认蓝当主色。
3. **UI 美 = 一等公民**，不得再标成可无限延期的 P2 化妆品。

**并行维持的能力轨（不冻结、不大扩）：**

- 继续维护版本保存 / 分享 / presence（修 bug、可达性、可信反馈）。
- **本季禁止新开**：版本分支、双向 live sync、MCP / 公开 API 产品实现码（ADR-0013 仍为规划）。

**降权：**

- 企业审批流不当作北极星主注。
- 不改变图观感/分享欲的 chrome 微切片。
- meta 循环 prompt 空转改写。

循环指令必须：**双轨等权选题；禁止向用户开放式问方向；禁止碎活凑数。**

## 后果

- 正面：激活与口碑（截图传播）有清晰主线；能力资产不丢；agent 循环停止方向抖动。
- 代价：本季少做「同步/分支/MCP 产品码」与审批深水；部分 chrome 债后置。
- 风险：只化妆不动建模回路 → 用走查+E2E 约束「图可读可分享」必须可验证；布局质量：导入/逆向/无坐标兜底已接共享 dagre（`utils/graphLayout`，默认 `nodesep` 64 / `ranksep` 120）；示例主图手排收紧 + Frame padding 32；节点密度/PK·FK 徽章/自定义 `erdSmooth` 边（同表对多 FK 肘距分流 + 中间表 `centerX`/`bypassY` 避让 + 同 midX 通道干道 bundling + 叠表缝 mid-corridor / 两弯 `escapeX` + 稀疏 Hanan A*）已落地；三壳 chrome（顶栏 64 / 去水印 / Home 表面 token）已对齐；导入/密 FK 走查续切片。
- 与既有 ADR：不推翻 ADR-0001（ReactFlow）、ADR-0012（定位）、ADR-0013（MCP 规划不实现）；本篇只定**本季投注权重**。

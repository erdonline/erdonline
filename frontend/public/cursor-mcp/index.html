闭环在铸造成功弹层：同一屏只显示一次明文，并给出已填 PAT 的 Cursor / Claude Code / Cline / Devin / VS Code 配置或命令。OAuth 下一切片；明文 PAT 不进 deeplink、不进仓库。

The mint-success dialog closes the loop: while plaintext is visible once, it provides PAT-filled Cursor, Claude Code, Cline, Devin, and VS Code artifacts. OAuth comes next; PATs never enter deeplinks or the repository.

Cursor

  1. 点「打开 Cursor」安装 URL。
  2. 去上方铸造 PAT。
  3. 在成功弹层复制已填 PAT 配置。
  1. Open Cursor and install the URL.
  2. Mint a PAT above.
  3. Copy the filled config from the success dialog.
{
  "mcpServers": {
    "erdonline": {
      "url": "https://api.erdonline.com/mcp",
      "headers": { "Authorization": "Bearer erd_pat_…" }
    }
  }
}

Claude Desktop

  1. 打开 App → Customize → Connectors。
  2. 点 + → Add custom connector。
  3. 粘贴 URL；等待下一切片 OAuth 后连接账户。
  1. Open App → Customize → Connectors.
  2. Click + → Add custom connector.
  3. Paste the URL; account auth awaits OAuth.

没有已证实的自定义安装 URI，也不能注入静态 Bearer header；Anthropic 云端 Connector 不能访问 localhost。

No evidenced custom install URI and no static Bearer-header injection. Anthropic’s cloud connector cannot reach localhost.

Claude Code

  1. 去上方铸造 PAT。
  2. 在成功弹层复制已填 PAT 命令。
  3. 粘到终端运行，直接写入 user scope。
  1. Mint a PAT above.
  2. Copy the PAT-filled command from the dialog.
  3. Run it to write user scope directly.
claude mcp add --transport http --scope user erdonline https://api.erdonline.com/mcp -H 'Authorization: Bearer erd_pat_…'

Cline

  1. 打开 Cline → MCP Servers → Remote Servers。
  2. 去上方铸造 PAT，复制已填配置。
  3. 粘贴并选择 Streamable HTTP。
  1. Open Cline → MCP Servers → Remote Servers.
  2. Mint a PAT and copy the filled config.
  3. Paste it and choose Streamable HTTP.
{
  "mcpServers": {
    "erdonline": {
      "type": "streamableHttp",
      "url": "https://api.erdonline.com/mcp",
      "headers": { "Authorization": "Bearer erd_pat_…" }
    }
  }
}

Cline 官方文档未提供 MCP 自定义安装 URI。

Cline documents no custom MCP install URI.

Devin Desktop (formerly Windsurf)

  1. 打开 Devin Desktop → MCPs / Add Server。
  2. 去上方铸造 PAT，复制已填配置。
  3. 写入 ~/.codeium/mcp_config.json 后刷新。
  1. Open Devin Desktop → MCPs / Add Server.
  2. Mint a PAT and copy the filled config.
  3. Write ~/.codeium/mcp_config.json, then refresh.
{
  "mcpServers": {
    "erdonline": {
      "serverUrl": "https://api.erdonline.com/mcp",
      "headers": { "Authorization": "Bearer erd_pat_…" }
    }
  }
}

官方 windsurf://windsurf-mcp-registry 只能打开 Marketplace，不会携带这份自定义配置。

The official windsurf://windsurf-mcp-registry opens Marketplace only; it does not carry this custom config.

Install ERD Online MCP in Cursor

One-click install opens the Cursor app. Replace ERD_PAT with your minted token after install.

Open in Cursor

If nothing happens, copy the JSON below into ~/.cursor/mcp.json and reload Cursor.

{
  "mcpServers": {
    "erdonline": {
      "command": "npx",
      "args": [
        "-y",
        "--package",
        "https://github.com/erdonline/erdonline/releases/download/mcp-v0.1.0/erdonline-mcp-0.1.0.tgz",
        "erd-mcp"
      ],
      "env": {
        "ERD_API_URL": "https://erdonline-production.up.railway.app",
        "ERD_PAT": "erd_pat_…"
      }
    }
  }
}

ERD Online MCP

让 Cursor / Claude / Cline 读懂你的 ER 图

30 秒接入：铸造 PAT → 粘贴 mcp.json → Agent 读取 projectJSON 并建议版本

1铸造 Personal Access Token

登录后进入 账户设置 → 访问令牌，创建一个 PAT。默认只读即可；若需要让 Agent 提版本，请勾选 versions:write。

铸造成功后弹层会给一个已填入 PAT 的 mcp.json，可直接复制。明文只显示一次。

2把配置粘进 MCP 客户端

下面 JSON 适用于所有支持 stdio MCP 的客户端。点击复制后，粘到对应位置并把 erd_pat_… 换成你的明文 PAT。

Cursor ~/.cursor/mcp.json 或点下方 Open in Cursor
Claude Desktop ~/Library/Application Support/Claude/claude_desktop_config.json
Claude Code ~/.claude/config.json 或环境变量
Cline / Roo VS Code mcp settings
Windsurf ~/.windsurf/mcp.json
mcp.json 
{
  "mcpServers": {
    "erdonline": {
      "command": "npx",
      "args": [
        "-y",
        "--package",
        "https://github.com/erdonline/erdonline/releases/download/mcp-v0.1.0/erdonline-mcp-0.1.0.tgz",
        "erd-mcp"
      ],
      "env": {
        "ERD_API_URL": "https://erdonline-production.up.railway.app",
        "ERD_PAT": "erd_pat_…"
      }
    }
  }
}
一键在 Cursor 中打开 完整文档
这个一键链接不会把你的 PAT 编进 URL。Cursor 打开后，仍需把明文 PAT 替换掉上面 JSON 里的 erd_pat_…。

3对 Agent 发出第一条指令

重载客户端后，尝试说：

  • 列出我的 ERD 项目 → 应出现 list_projects
  • 读取项目 X 的 projectJSON → 应返回模型结构
  • 建议一个新版本 → 可让 Agent 调用 create_version（需 versions:write）

所有写操作都需要你在设计器里做 diff 审批。API 200 不是人批准。

常见问题

点「一键打开」没反应？

请确保已安装 Cursor 0.40+ / Claude Desktop。直接复制上面的 mcp.json 粘到客户端也能用。

Agent 说 ERD_PAT 缺失？

erd_pat_… 是占位符。把铸造弹层里的明文 PAT 粘贴进去，不要直接发给 Agent。

可以接入 Claude / Cline / Windsurf 吗？

可以。只要客户端支持 stdio MCP，把同一 JSON 粘到对应配置位置即可。详见 完整文档。

会泄露我的数据库密码吗？

不会。MCP 返回的 projectJSON 里不含有数据库连接密码；只返回模型结构、字段、关系等。

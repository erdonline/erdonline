OAuth 将在下一切片加入。过渡期内，需要读取账户数据的客户端可在配置中加 Authorization: Bearer erd_pat_…；不要把明文 PAT 放进 deeplink 或提交到仓库。

OAuth comes in the next slice. During the transition, clients that support custom headers can use Authorization: Bearer erd_pat_…. Never put a plaintext PAT in a deeplink or commit it.

Cursor

  1. 点击上方「在 Cursor 打开」。
  2. 确认服务 URL 后安装。
  3. 需要账户数据时，在本机配置补 Bearer PAT。
  1. Click “Open in Cursor” above.
  2. Confirm the server URL and install.
  3. For account data, add a Bearer PAT locally.
{
  "mcpServers": {
    "erdonline": {
      "url": "https://api.erdonline.com/mcp",
      "headers": { "Authorization": "Bearer erd_pat_…" }
    }
  }
}

Claude Desktop

  1. 打开 Settings → Connectors。
  2. 添加自定义 Connector，粘贴上方 URL。
  3. 保存并重新连接。
  1. Open Settings → Connectors.
  2. Add a custom connector and paste the URL.
  3. Save and reconnect.

Anthropic’s cloud connector cannot reach localhost. Remote account authentication awaits the next OAuth slice.

Claude Code

  1. 在终端运行下面命令。
  2. 确认 scope 为 user。

  1. Run the command below.

Cline

  1. 打开 Cline MCP Servers。
  2. 添加远程服务并粘贴配置。
  3. 保存后检查工具列表。
  1. Open Cline MCP Servers.
  2. Add a remote server and paste the config.
  3. Save, then check the tool list.
{
  "mcpServers": {
    "erdonline": {
      "type": "streamableHttp",
      "url": "https://api.erdonline.com/mcp",
      "headers": { "Authorization": "Bearer erd_pat_…" }
    }
  }
}

Windsurf

  1. 打开 ~/.codeium/windsurf/mcp_config.json。
  2. 加入下面的服务配置。
  3. 重载 Windsurf。
  1. Open ~/.codeium/windsurf/mcp_config.json.
  2. Add the server config below.
  3. Reload Windsurf.
{
  "mcpServers": {
    "erdonline": {
      "serverUrl": "https://api.erdonline.com/mcp",
      "headers": { "Authorization": "Bearer erd_pat_…" }
    }
  }
}

VS Code Copilot

  1. 打开工作区 .vscode/mcp.json。
  2. 在顶层 servers 加入配置。
  3. 启动该 MCP 服务。
  1. Open workspace .vscode/mcp.json.
  2. Add the config under top-level servers.
  3. Start the MCP server.
{
  "servers": {
    "erdonline": {
      "type": "http",
      "url": "https://api.erdonline.com/mcp",
      "headers": { "Authorization": "Bearer erd_pat_…" }
    }
  }
}

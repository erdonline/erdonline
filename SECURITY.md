# 安全策略 · Security Policy

## 报告漏洞 / Reporting a Vulnerability

如果你发现安全漏洞，请**不要**公开提交 Issue。
If you discover a security vulnerability, please do **not** open a public issue.

请通过以下方式私下报告 / Please report privately:

- 通过 GitHub Security Advisories（推荐）/ via GitHub Security Advisories (preferred)
- 或联系维护者邮箱 / or email the maintainers

报告时请包含 / Please include:

- 漏洞描述与影响范围 / description and impact
- 复现步骤 / steps to reproduce
- 受影响的版本 / affected versions

我们会在确认后尽快修复，并在修复发布后致谢报告者（如愿意）。
We will confirm and fix as soon as possible, and credit reporters upon release (if desired).
